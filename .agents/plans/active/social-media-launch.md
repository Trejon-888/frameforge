## Strategic Foundation

Kino is not announced. Kino is demonstrated through results.

Every piece of IX content produced with Kino is a Kino ad. The viewer never sees "here's our tool." They see content that is noticeably better than everything else in the space. When they ask "how?" — that's the conversion moment. The answer is IX.

**The loop:**
```
Kino-produced content → viral reach → "how did you make that?"
→ "join IX" → more members → more Kino content → repeat
```

**What we never do:** Announce Kino as a developer tool. No Show HN. No r/webdev. No "npm install @kinohq/core" as primary CTA. That's a different product. This is a community weapon.

## What Kino Access Means (Community Model)

- npm packages are public — technically anyone can install
- But Kino is never promoted as a standalone public tool
- IX members get: templates, the edit agent pipeline, support, the community
- The VALUE of Kino comes from the IX ecosystem around it, not the tool alone

## Success Metrics (Not GitHub Stars)

- IX community applications/joins per week
- "How did you make that?" engagement on content
- Content reach (impressions, shares, saves)
- Quality gap: IX content vs. competitor content in same niche
- DMs from people wanting Kino/IX access
