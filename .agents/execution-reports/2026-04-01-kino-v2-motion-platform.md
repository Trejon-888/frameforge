## Architecture Decisions

- **ADR-009:** Captions rendered via ASS/libass in FFmpeg, not Puppeteer. Same engine as Premiere/Resolve. 100x faster for text rendering.
- **ADR-010:** Keyframe engine is renderer-agnostic — outputs resolved values, any renderer (Canvas 2D, DOM, FFmpeg expressions) can consume.
- **ADR-011:** Scene composition v2.0 format is the contract between AI agents and kino. Open element system — no fixed type list.
- **ADR-012:** Old component system kept for backward compat. Keyframe engine is the replacement path. Remove components once scene compiler is proven.
