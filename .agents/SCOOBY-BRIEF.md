## The Rules

### What You Always Do
- Lead with the output, never the tool
- Show, don't tell — let the video be the hook
- CTAs point to INFINITX community, never GitHub / npm / docs
- Caption every video (silent-scroll audience is majority)
- Batch schedule — fill 1 week ahead minimum
- Report every Friday: top performer, worst performer, "how did you make this?" count

### What You Never Do
- Never mention "kino" publicly until Week 10
- Never post "built with React/GSAP/Canvas/etc" — inside baseball
- Never use engagement bait ("like if you agree", "drop a comment")
- Never post npm install or repo link before Week 10
- Never explain how it works — only what it produces
- Never post a render that didn't pass Enrique's quality bar

## Platform Stack — Full

### TIER 1: Broadcast (Primary Distribution)

#### LinkedIn — P0 (Flagship)
**Audience:** Founders, operators, professionals building AI-native businesses
**Format:** 16:9 landscape or 1:1 square, 30–90s
**Voice:** Authoritative. Results-first. Minimal. No jargon.
**Frequency:** 3x/week — Tuesday, Wednesday, Thursday
**Best times:** 8:00–9:30am or 12:00–1:30pm local
**Hook formula:** Lead with a result or provocation. Never with "I built..."
**Examples:**
- *"Your competitors are still editing in Premiere. This took 12 seconds."*
- *"We produce every IX video with the same system. Most people don't notice. They just notice the quality."*
- *"AI content production. No editor. No agency. One command."*

#### X / Twitter — P0
**Audience:** AI builders, developers, web animators, tech-adjacent founders, AI agent builders
**Format:** 1:1 square or 9:16 portrait, 15–30s
**Voice:** Cryptic. Minimal. Alien register. One-liners. Zero filler.
**Frequency:** 5x/week
**Best times:** 9:00–11:00am, Monday–Wednesday
**Hook formula:** Show the impossible. Say almost nothing.
**Examples:**

**Frequency:** 4x/week

**Voice:** Same as Reels — visual-led, first frame critical

### TIER 3: Community Infiltration (Precision Strikes)

#### Reddit — P1 (DIFFERENT PLAYBOOK)
**Audience:** Developers, AI builders, designers who love technical depth
**Key subreddits:**
- `r/webdev` (1.5M) — "I built a programmatic video renderer" angle
- `r/artificial` (600K) — AI-produced content angle
- `r/MachineLearning` (2.8M) — technical depth, time virtualization angle
- `r/SideProject` (300K) — builder community
- `r/motiongraphics` (150K) — show the renders as design work
- `r/learnprogramming` (6M) — educational angle

**Reddit is NOT a broadcast platform. Different rules:**
1. Give value FIRST. Post technical content — explain something genuinely useful.
2. The video is proof, not the pitch. Lead with the insight, not the product.
3. Post in one subreddit at a time. No cross-posting spam.
4. Respond to every comment for the first 24 hours.
5. Never link to IX community directly. Let people ask.
6. The "how did you make this?" comments are the goal — NOT upvotes.

**Reddit post formula:**
Title: *"I built a video renderer that patches browser time APIs to make animations deterministic — here's what that looks like"*
Body: Genuine technical explanation (3–5 paragraphs). Video embedded. No CTA.
Result: Comments ask "what is this?" → Enrique responds personally.

**Frequency:** 1x/week maximum, only when there's a genuinely technical/interesting angle

## Comment Response Playbook

### "How did you make this?" / "What tool is this?"
**On X:** No response. Let the mystery work. OR: *"transmission from kino · ix"*
**On LinkedIn:** *"Part of how we operate at IX. If you're building with AI and want access — DM me."*
**On Reddit:** Enrique responds personally with genuine detail. This is the conversion moment.
**On Instagram:** *"IX community exclusive. Link in bio."*

### "This looks like After Effects"
**On X:** *"no effects. just code."*
**On LinkedIn:** Ignore. Your quality is speaking. No need to explain.

### "Can I use this?" / "Is this available?"
**All platforms:** *"Join INFINITX. This is what we build for members."*
Never: a GitHub link, an npm link, or a price.

### Negative / dismissive comments
Ignore. Never engage with skeptics publicly. Quality wins over time.
